# GRID / Study

Минималистичный планировщик учёбы с неоновым интерфейсом, вдохновлённым научной фантастикой. Первый прототип, подготовленный Elbek Elmurodov с помощью ChatGPT. Не связан с Disney или франшизой TRON.

## Возможности
- Создание, редактирование, удаление и завершение задач.
- Предмет, срок и приоритет задания.
- Поиск, фильтры, статистика и индикатор прогресса.
- Автоматическое сохранение в localStorage браузера.
- Экспорт задач в JSON (импорт пока не реализован).
- Адаптивный интерфейс на русском языке.

## Запуск
Откройте `dist/index.html` в современном браузере. Для стабильного сохранения рекомендуется запускать через локальный HTTP-сервер: `python -m http.server 8000 --directory dist`, затем открыть http://localhost:8000.

Стек: HTML, CSS, JavaScript. Нет зависимостей, регистрации или серверной базы данных. Данные привязаны к браузеру и адресу сайта. Очистка данных браузера удаляет задачи. Экспортируйте важные данные заранее. Синхронизация и уведомления не реализованы.

## Публикация на GitHub
1. Создайте пустой публичный репозиторий `grid-study` в своём аккаунте GitHub.
2. Распакуйте архив и загрузите содержимое папки проекта через Add file → Upload files. Сохраните папку `dist` и файлы README.md и LICENSE.
3. Для GitHub Pages переместите содержимое `dist` в корень репозитория. В Settings → Pages выберите Deploy from a branch, ветку main и /(root).

## Проверка вручную
Добавьте задачу со сроком и предметом. Перезагрузите страницу и убедитесь, что она сохранилась. Измените задачу, отметьте выполненной, проверьте фильтры и поиск. Экспортируйте JSON и проверьте содержимое. Удалите тестовую задачу.
